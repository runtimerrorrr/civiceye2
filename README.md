# SafeStreets HYD - Civic Infrastructure Hazard Monitoring

Report potholes, waterlogging, open manholes, broken streetlights in Hyderabad.

## How to run
1. Download all files
2. Open `index.html` in browser - No server needed!
3. Or deploy free on Vercel / Netlify / GitHub Pages

## Features
- Live map with Leaflet + OpenStreetMap
- Report with photo, location, severity
- Upvote / Mark Fixed
- Filter by hazard type
- Works on mobile
